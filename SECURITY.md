# Security Policy

## Supported versions

Security fixes are provided on the latest maintained branch/version of this fork.

## Reporting a vulnerability

Please do **not** open public issues for security-sensitive reports.

Report privately to repository maintainers with:

- Affected version/tag
- Reproduction details
- Impact assessment
- Any proof-of-concept data

## Response goals

- Acknowledge report receipt
- Validate impact
- Prepare a fix and release guidance
- Credit reporters when appropriate
