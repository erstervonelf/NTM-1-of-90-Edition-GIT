# Support

## Where to ask for help

- Use GitHub Issues for reproducible bugs and feature requests.
- Use the compatibility issue template for mod conflict/performance/environment problems.

## Before opening an issue

Please gather:

- Fork version/tag
- Minecraft + Forge versions
- Full mod list
- Steps to reproduce
- Logs/crash reports

## Triage notes

Issues missing reproduction details may be marked as needing more information.
